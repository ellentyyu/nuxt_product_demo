# Nuxt 3 商品瀏覽/ 報名專案 demo
demo site: https://nuxt-product-demo.onrender.com/

## Node version
v20.11.0

## Setup

Make sure to install the dependencies:

```bash
# npm
npm install

# dev
npm run dev

# build the application for production
npm run build

# locally preview production build
npm run preview
```
